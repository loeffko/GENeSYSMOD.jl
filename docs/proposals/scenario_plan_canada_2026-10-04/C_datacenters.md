Conventions
- Money is CAD unless stated. Conversion used: **1 CAD = 0.685 EUR** (Bank of Canada 2023 annual averages: 1.3497 CAD/USD, 1.4597 CAD/EUR, https://www.bankofcanada.ca/rates/exchange/annual-average-exchange-rates/ ; identical to the project convention 1 USD = 0.925 EUR). Project costs below are nominal 2025-26 CAD and are NOT deflated to 2023.
- "snippet - verify" = figure seen only in a search-result snippet, page not fetched. "secondary" = aggregator/law-firm/press page that cites a primary source I could not open. "NOT FOUND" = searched, no public source. "(own assumption)" / "(own calc)" = not from a source.
- Method limit: the session's web-search budget ran out part-way; topics (e), (f) and (g) rely on direct page fetches of known URLs only. See Gaps.
- Primary data parsed directly for this note: AESO Connection Project Lists Jun 2025 - Sep 2026 (xlsx), IESO 2026 APO Demand Forecast Module data (xlsb), CER EF2026 pages.

## S6 - Proposed variants

How to read: demand = annual-average connected data-centre MW x 8.76 x load factor. **Load factor 0.85 is my own assumption** for every MW-based figure (the model base states its GW at 100 %); Ontario uses the IESO TWh directly. All phasing choices are marked. Base for comparison: 71 / 178 / 269 TWh (2030 / 2035 / 2040) = 9.5 / 23.9 / 36.1 GW connected at LF 0.85, or 8.1 / 20.3 / 30.7 GW at LF 1.0 (own calc).

Headline: **every sourced forecast and the announced-project pipeline sit BELOW the model base.** CER EF2026 Higher adds only 2.7 GW by 2030 and 12 GW by 2050 (~100 TWh in 2050); ISED's need estimate is 5.5 GW by 2030 (41-48 TWh); the system operators' own numbers for Ontario + Québec + BC add up to ~40 TWh in 2040. The base (269 TWh in 2040) can only be reached if roughly the whole Alberta queue (20.7 GW, of which 92 % has no in-service date) is built. So S6 "acceleration" is, relative to the base, only a tailwind in variant C.

Notes for the model

In C the dedicated gas alone is 6.9 / 22.7 / 28.2 GW, i.e. total Canadian gas would rise instead of falling from 32 to 27 GW.

- All variants keep Alberta as the dominant province (26-72 %); with one Canada node this is invisible, but hydro-rich BC, Québec and Manitoba are the provinces that ration data centres, so additional load is gas-supplied almost by construction.
- The base-year value (17 TWh in 2025) looks high against sourced operating load (Hydro-Québec 190 + 115 MW, IESO 4.5 TWh in 2027, McCord 449 MW tracked, ISED 337 MW AI); a bottom-up 2025 figure is closer to 9-11 TWh (own estimate) - worth a check before layering variants on top.
