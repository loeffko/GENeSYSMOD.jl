# Research B: nuclear growth and northern/remote power (Canada scenarios 3, 5)

Research date: 2026-10-04. STATUS: S3 and S5 complete. S3 was researched with web search plus page fetches;
S5 only with direct page fetches (the session's web-search budget ran out) - see the limitation note at the top of S5.

Conventions
- CAD figures as published (nominal unless stated). Conversion used here: **1 CAD = 0.72 USD = 0.666 EUR**
  (0.72 USD/CAD is the rate implied by 2025-26 trade-press conversions - WNN: CAD 20.9 bn = USD 15 bn (0.718);
  CAD 26.8 bn = USD 19.1 bn (0.713); ANS: CAD 300 M = USD 219.4 M (0.731) - times the project rate 1 USD = 0.925 EUR).
  Model capex 10,000 EUR/kW therefore equals about 15,000 CAD/kW.
- "snippet - verify" = figure seen only in a search-result snippet, page itself not fetched/readable.
- "NOT FOUND" = searched, no public source located.
- "(own assumption)" = not from a source; my inference or scheduling assumption.
- "Base" = frozen model base run for Canada (large nuclear 12.9/12.9/15.0/15.6 GW in 2025/2030/2035/2040, max 25.0 in 2040;
  SMR 0/0/0.32/0.32 GW; capex 10,000 EUR/kW flat).
